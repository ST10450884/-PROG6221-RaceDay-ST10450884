# RaceDay System Plan

## System Purpose

RaceDay will replace paper-based event registration, disconnected spreadsheets and separate communication channels with one central event management system.

The platform is intended for South African road-running, walking and cycling events. It will allow organisers to manage events and allow participants to register for suitable event categories.

## Organiser Role

An organiser will be able to:

- Create new events.
- View, edit and delete events they created.
- Create and manage event categories.
- View participant enrolments.
- Confirm or cancel enrolments.
- Capture and update participant results.
- View event and participant information.

## Participant Role

A participant will be able to:

- Create an account.
- Log in securely.
- View and update their profile.
- Browse upcoming events.
- View event categories.
- Enter an event by selecting a category.
- View and cancel their own enrolments.
- View their personal results and performance history.

## Planned Technologies

The complete RaceDay system will use:

- C# and ASP.NET Core
- ASP.NET Core Web API
- ASP.NET Core MVC
- Microsoft SQL Server
- SQL Server Management Studio
- GitHub and GitHub Actions
- Azure Blob Storage
- Docker

## Part 1 Scope

Part 1 contains system planning only. It will include:

- An Entity Relationship Diagram.
- A complete API endpoint plan.
- A SQL Server database creation script.
- Realistic sample data.
- A GitHub Actions validation workflow.

No API or MVC application code will be written during Part 1.
