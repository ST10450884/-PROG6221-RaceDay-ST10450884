Project Overview

RaceDay is a planned full-stack event management system for South African road-running, walking and cycling events. It aims to replace paper-based registration, disconnected spreadsheets and separate communication channels with one central platform.

The system will allow organisers to create and manage events, event categories, participant enrolments and race results. Participants will be able to create accounts, browse upcoming events, select event categories, manage their enrolments and track their personal results.
